Los ficheros aquí presentes se tratan del firmware empleado por un dispositivo Detector de Resonancia Magnetoelástica, una interfaz gráfica (GUI) para controlar y monitorizar dicho dispositivo y los modelos 3D del sistema de solenoides encargado de generar y medir el campo magnético. Ambos forman parte del Trabajo de Fin de Grado del grado en ingeniería electrónica realizado por el autor titulado "Desarrollo de una plataforma compacta de detección de resonancia
magnetoelástica".
